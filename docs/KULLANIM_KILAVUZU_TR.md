# Kısa Kullanım — v42

1. **Chartshunter Media Studio.exe** dosyasını aç.
2. **0 İndir** sekmesine linklerini yapıştır ve **İndirmeyi Başlat** de.
3. Çoklu indirmede link kutusundaki satırlar canlı olarak işaretlenir:
   - **Yeşil:** başarıyla indirildi.
   - **Kırmızı + üstü çizili:** indirilemedi.
   - **Sarı:** şu anda işleniyor.
   - **Gri:** iptal edildi / yarım kaldı.
4. Link kutusunun altındaki **Durum** satırında kaç videonun indirildiğini, başarısız olduğunu ve beklediğini görebilirsin.
5. Alt ilerleme panelindeki **Video X/Y** alanı hangi videoda olduğunu ayrıca gösterir.
6. Tarayıcı çerezlerinde varsayılan **Otomatik (Brave öncelikli)** seçimi kullanılır.
7. VK/VK Video erişilemiyorsa uygulama aynı linkte uzun süre dönmek yerine sıradaki videoya geçer.
8. Video ve ses ayrı parçalar halinde gelirse normal birleşimden sonra ek FFmpeg kurtarma/birleştirme denenir.

Varsayılan indirme ayarları: **Auto+ / MP4 1080p / Hızlı / Zorlayıcı Açık / Adult-video-host Açık / Brave öncelikli otomatik çerez**.
