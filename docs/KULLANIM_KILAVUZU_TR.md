# Kısa Kullanım — v40

1. **Chartshunter Media Studio.exe** dosyasını aç.
2. İndirme için **0 İndir** sekmesine linkleri yapıştır ve **İndirmeyi Başlat** de.
3. Eksik bir motor/paket gerekiyorsa uygulama o anda sorar. Onay verirsen bir kez hazırlanır.
4. Kurulu bir bileşenin yeni sürüm bilgisi varsa, o bileşeni kullanacağın anda **Güncelle / mevcut sürümle devam et** seçeneği çıkar.
5. Altyazıda Whisper modeli cache'te yoksa model indirme onayı kullanım anında sorulur. Cache'teyse tekrar indirilmez.
6. Sistem durumunu görmek için **Kontrol** sekmesini kullan.

Varsayılan indirme ayarları: Hızlı + Zorlayıcı Açık + Adult/video-host Açık.
