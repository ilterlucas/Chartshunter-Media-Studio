# Publishing

Chartshunter Media Studio Stable sürümleri GitHub Actions ile otomatik paketlenir.

`.github/workflows/release.yml` Python compile/self-test, Windows launcher build, ZIP, SHA256 ve GitHub Release adımlarını çalıştırır.

v43 release asset'leri:

- `ChartshunterMediaStudio_v43_Stable.zip`
- `Chartshunter.Media.Studio.exe`
- `Repair.Update.exe`
- `SHA256SUMS.txt`

Stable yayın öncesi v43 development workflow başarıyla tamamlanmalıdır.
